# Quiz Application

A console-based Quiz Application built in Java as part of my internship tasks at InCodeVision. Uses ArrayList and HashMap collections to store and manage questions and results.

## Features

- 10 multiple choice Java questions
- 4 options per question
- Instant feedback after each answer
- Shows correct answer if wrong
- Final score and grade calculation
- Question by question result summary

## Concepts Used

- ArrayList to store questions and options
- HashMap to store question results
- Classes and Objects (OOP)
- Loops and control structures
- Input validation and exception handling
- Grade calculation based on percentage

## How to Run

1. Make sure you have JDK installed.
2. Compile the program:
   ```
   javac QuizApplication.java
   ```
3. Run the program:
   ```
   java QuizApplication
   ```
4. Enter your name and answer each question by typing the option number (1-4).
